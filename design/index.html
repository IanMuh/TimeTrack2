离线优先的时间追踪
双情境 · 三档自适应 · 一个交互系统

依据《UI功能契约 v1.0》产出 6 个高保真 HTML 设计稿。同一产品、同一套数据语义：Windows 桌面长时驻留， Android 移动单手一瞥；<600 / 600–840 / ≥840 三档断点与浅深双主题全覆盖。所有操作经统一指令通道分发， 反馈语义系统级一致。点击下方卡片查看各页面设计稿。

设计决策摘要

色彩令牌

品牌主色 + 语义色 + 活动色板（深浅同色相策略）

品牌主色
indigo-600 · 主按钮 / 强调 / 导航高亮
语义色
成功 警告 危险 信息
活动色板（8 色）

深色底使用 bg-{c}-500/10 大面积底色 / text-{c}-400 文字，保持同色相可读性；「未分配」固定 zinc-400。

字体与数字

Inter + Noto Sans SC / Microsoft YaHei 中文兜底；标题 tracking-tight，字重整体压一档。

标题 24–28px 01:24:36 计时数字 tnum 等宽，不跳动

断点三档

< 600
紧凑 · 底部导航 + 计时条两层叠置
600–840
中宽 · 底部导航
≥ 840
宽屏 · 232px 侧导航 + 撤销/重做 + 同步状态

浅 / 深双主题

默认浅色（zinc-50 底 / white 卡片）；深色（zinc-950 底 / zinc-900 卡片）完整推导，非浅色附注。 每个页面右上角有切换按钮，可验收双主题。

契约 §10 对照清单

静态对照文本 · 逐项详见对应页面设计稿

✓ = 设计已覆盖。跨页场景（选择器 / 弹窗 / 撤销 / 平台驻留）详见 system.html；各页专有场景详见对应页面。

不变式（§2）

  • ✓离线优先，页面不因网络阻塞，同步状态可感知
  • ✓删除分类 = 递归 + 单条撤销记录，删除入口有确认与范围提示
  • ✓历史条目按快照展示，统计按当前归属
  • ✓跨天滚转与跨天编辑拆分在 UI 有对应处理
  • ✓「未分配」唯一 + 相邻合并（阈值可配）可被用户理解
  • ✓操作反馈（成功/失败/可撤销）系统级一致
  • ✓数据变更后所有页面即时一致
  • ✓is_auto 条目可识别、统计可排除、可批量清理、编辑有防误保护
  • ✓强制更新不可跳过；更新失败有浏览器兜底
  • ✓LAN 主机无任何自动开启路径

应用壳（§3）

  • ✓5 页导航（图标+文字），无首页/报告页
  • ✓宽屏侧导航 / 中宽与紧凑底部导航；紧凑两层叠置可行
  • ✓全局计时条：活动名 + 实时计时 + 回计时页 + 任意页切换活动 + 未运行占位
  • ✓撤销/重做：桌面常驻 + 移动菜单（含动作名）+ Ctrl+Z/Y + 输入框让位 + 不可用时禁用并提示

计时页（§4.1）

  • ✓会话焦点（活动/实时时长/今日累计/会话数）
  • ✓停止 + 原子切换
  • ✓快捷区含「临时活动」与「新增活动」固定入口，运行中有区分态
  • ✓单击选中/再击确认（中间态可见）、双击直切、长按/悬停编辑
  • ✓三态

今日页（§4.2）

  • ✓任意日期查看（日历 + 步进）
  • ✓4 指标 + 较前日对比
  • ✓分类分组聚合：折叠、祖先链路径、「未分类」置底、组内活动明细
  • ✓分类多选筛选联动列表与指标
  • ✓宽屏时间线预览 + 跳转
  • ✓三态

时间线页（§4.3）

  • ✓添加条目 + 日期步进 + 跨度切换 + 条目/日志视图切换
  • ✓汇总 3 项
  • ✓时间比例可视化（刻度/日期分组/点击编辑/滚动缩放/分段 1–12 可调）
  • ✓条目列表流（时间/活动/备注/点击编辑）
  • ✓未来日期横幅
  • ✓编辑对话框：搜索 + 现场新建 + 起止编辑 + 保持运行开关 + 备注 + 合并/拆分/延伸 + 删除/取消/保存 + 4 类校验
  • ✓日志视图 4 字段；is_auto 标识；三态

  • ✓三态

合并选择器（§5.1）

  • ✓桌面弹窗（树 + 活动集 + 搜索 + 双新建）/ 移动抽屉（搜索 + 分类行 + 活动集）
  • ✓选分类过滤、选活动即完成
  • ✓新建/编辑活动内嵌（名/色/持续临时/主副分类）
  • ✓递归删除内嵌 + 确认提示 + 单条撤销
  • ✓空分类入口、无分类退化「全部活动」
  • ✓变更实时刷新；长按/右键管理；>3 层祖先链呈现

弹窗体系（§5.2）

  • ✓三条决策规则成立
  • ✓6 个场景载体分配正确（含强制更新不可跳过）

后台记录（§6）

  • ✓授权卡（Android 跳系统设置 / Windows 说明条）+ 未授权禁用总开关
  • ✓规则列表字段与操作齐全（含 per-rule 同步开关）
  • ✓规则表单（模式/类型/目标活动/同步开关/优先级说明）
  • ✓Android 首次全屏引导（含隐私承诺与「暂不开启」）
  • ✓托盘三行为 + 状态提示；前台服务通知（映射文案/点击回主/暂停动作）

更新（§7）

  • ✓10 个状态在更新卡完整呈现
  • ✓进度 + 速度 + 取消；忽略版本持久化；稍后提醒
  • ✓静默检查仅 Snackbar；强制更新唯一操作；降级浏览器兜底；双平台安装差异呈现

技术（§8）

  • ✓Material 3 + fl_chart 可实现性自评（无可实现性问题）
  • ✓三档断点 + 深浅色全覆盖
  • ✓键盘可达；计时数字稳定不跳动（tnum）
  • ✓文案中文占位、无硬编码键名要求冲突
