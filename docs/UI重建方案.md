# TimeTrack2 UI 重建方案

> 状态：已确认（2026-10-24）。视觉语言沿用 `design/DESIGN_LANG.md`（indigo/zinc、
> 圆角 16、Inter），本次只改信息层级、密度与自适应，不换风格。
>
> 已确认的选择：计时页活动区 = **紧凑分组列表**；设置页 = **路由化主从**
> （`/settings/:section`）；设置分区导航 = **10 项扁平列表**（不分组）。

## 1. 问题与目标

| 页面 | 现状问题 | 目标 |
|---|---|---|
| 计时 | 1280 宽下卡片约 288×165，活动名仅 14px；列数上限 4，宽屏卡片被拉大；顶部留白 40 + 区块间距 48 | 同屏条目约 2.5×，字号/行高与信息量匹配，列数随宽度增长 |
| 全局 | 壳层统一 `max-w-5xl=1024`，宽屏两侧大留白；页面内 208/260/320/420/760 等固定宽度散落；窗口无最小尺寸 | 内容宽度按页面语义分配；窗口 960×640 下限；固定尺寸改为弹性 |
| 统计 | 筛选树 260 固定、占比条 140 固定；柱图/环图固定高度上下堆叠，宽屏被拉平；分类信息分散在筛选树与聚合行 | 两栏主从 + 响应式图表；分类树表可下钻，筛选与聚合同一事实源 |
| 撤销/重做 | 侧栏底部两个 36px 图标 + 一行小字，禁用态弱、无操作对象 | 44px 操作卡（图标+文字+快捷键+tooltip 对象），窄屏进 AppBar |
| 设置 | 10 个分区全部铺在一条滚动里，“导航”只是锚点滚动 | 路由化主从：选分区只显示该分区页 |

## 2. 布局令牌（PR-A 已落地）

`lib/constants/layout.dart`：

- 断点：`compact = 600`、`expanded = 840`（侧栏/底部导航切换）、`wide = 1280`。
- 内容最大宽：计时 `1440`、今日 `1120`、统计 `1440`、设置 `1280`、表单 `760`。
- 间距令牌：4 / 8 / 12 / 16 / 24 / 32。

`lib/components/page_frame.dart`：`PageFrame(maxWidth, child)` 水平居中并限宽；
壳层不再统一约束内容宽度。

窗口最小尺寸：`windows/runner/win32_window.cpp` 处理 `WM_GETMINMAXINFO`，
下限 960×640（按 DPI 缩放）。

## 3. 计时页（PR-B）

- 活动区：按分类分组的紧凑列表；行高 56。
  - 左：色点 10 + 活动名 15/w500；第二行分类路径 12（有则显示）。
  - 右：今日时长 13 等宽数字 + 运行中徽标；整行 hover，运行中行主色左侧指示条。
  - 分组头 32，可折叠（会话内记忆）；无活动时行内 CTA 创建。
- 列数：< 640 单列；640–1199 双列；≥ 1200 三列；每列最小 320。
- 焦点区：顶部留白 16、区块间距 24；计时字号按宽度 72/60/48；说明单行，
  细节进 tooltip；按钮高 44。
- 搜索框 + 分类筛选 chips 合并到列表头部（宽屏一行、窄屏两行），即时过滤。

## 4. 统计页（PR-C）

- 两栏：左筛选 280（≥ 1200 常驻，否则折叠为「筛选 · 已选 N」弹层）；右内容
  最大 1120。
- 头部两行：标题 + 范围 segmented；维度 tabs（4 种）+ 排除自动 + 总计（28px）。
- 图表：≥ 1024 日分布柱状图（flex 3）与占比环形图（flex 2）并排、高 240；
  窄屏堆叠；柱宽按可用宽度均分，环图图例换行网格。
- 分类聚合改树表：名称（层级缩进 16）+ 弹性占比条 + 时长 + 条目数；行点击
  下钻/筛选，与左侧筛选树选中态同步。
- 日明细：行高 40，占比条弹性。

## 5. 撤销/重做（PR-D）

- 宽屏侧栏底部：分隔线 + 44px 操作卡，两个等宽按钮（图标 18 + 文字 13），
  下方 12px `Ctrl+Z / Ctrl+Shift+Z`；tooltip 显示「撤销：<对象>」；禁用态整卡
  降透明度 + 原因 tooltip。
- 窄屏：顶部 AppBar 右侧两个 44×44 图标按钮，行为一致。

## 6. 设置页（PR-D）

- 路由：`/settings` 重定向 `/settings/general`；`/settings/:section` 挂在
  settings 分支下，深链可用，切分区不丢壳层保活。
- 宽屏 ≥ 840：左 240 导航（10 项扁平列表）+ 右只渲染选中分区，正文最大 760。
- 窄屏 < 840：`/settings` 为分区列表页（行 56：图标 + 标题 + 副标题 + chevron），
  点入推进 `/settings/<section>`，系统返回/手势可回；进入时保留上次分区。
- 只构建当前分区；未提交的表单输入不跨分区保留（现有交互均为显式保存）。

## 7. 推进顺序与验收

1. **PR-A**（本次）：布局令牌 + `PageFrame` + 壳层去统一限宽 + 窗口最小尺寸 + 方案文档。
2. **PR-B**：计时页（焦点区压缩 + 分组列表 + 自适应列）。
3. **PR-C**：统计页（两栏 + 响应式图表 + 分类树表）。
4. **PR-D**：设置路由化主从 + 撤销/重做改版。

每个 PR 的验收：

- `flutter analyze` 0 issues；`flutter test` 全绿。
- 受影响页面补 3 档宽度 widget 测试（480 / 800 / 1280）；新增交互（深链/返回、
  两栏切换、撤销按钮态）各自有用例。
- 手工冒烟：窗口 960×640 → 1920×1080 拉伸、textScale 1.0/1.3、中英文。
